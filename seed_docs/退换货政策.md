# 退换货政策

## 政策概述

为保障您的消费权益，我们提供完善的退换货服务。本政策适用于在本平台购买的所有商品。请您在购买前仔细阅读本政策，如有疑问可咨询客服。

## 退货条件

### 适用范围
以下情况可以申请退货：
1. 商品存在质量问题，如破损、故障、无法正常使用等
2. 商品与描述不符，如规格、型号、颜色等与订单信息不一致
3. 商品错发、漏发
4. 商品在7天内无理由退货（需满足以下条件）

### 无理由退货条件
1. 商品保持原样，未经使用、安装、激活
2. 商品包装完整，配件齐全
3. 商品标签、吊牌未剪裁
4. 商品不影响二次销售
5. 购买时间在7天内（以签收时间为准）

### 不适用退货的情况
以下情况不支持退货：
1. 定制商品、个性化商品
2. 鲜活易腐商品，如食品、鲜花等
3. 虚拟商品，如软件授权、电子书等
4. 超过7天无理由退货期限
5. 商品已被使用、磨损、损坏
6. 商品包装、配件缺失
7. 购买时已明确说明不支持退货的商品

## 换货条件

### 适用范围
以下情况可以申请换货：
1. 商品存在质量问题
2. 商品规格、型号与订单不符
3. 商品错发、漏发
4. 尺寸不合适（仅限服装、鞋帽等商品）

### 换货期限
- 质量问题换货：自签收之日起15天内
- 尺寸不合适换货：自签收之日起7天内

### 换货流程
1. 在订单页面点击"申请换货"
2. 选择换货原因，填写相关信息
3. 上传商品照片（如有质量问题）
4. 提交申请，等待客服审核
5. 审核通过后，寄回原商品
6. 收到退货后，我们立即寄出新商品

## 退货流程

### 第一步：提交申请
1. 登录账户，进入"我的订单"
2. 找到要退货的订单，点击"申请退货"
3. 选择退货原因，填写退货说明
4. 如有质量问题，上传商品照片
5. 提交申请

### 第二步：等待审核
客服会在1-2个工作日内审核您的退货申请。审核期间请保持手机畅通，客服可能会与您联系确认详情。

### 第三步：寄回商品
审核通过后，请按照以下步骤寄回商品：
1. 打包商品，确保包装完整
2. 附上退货单（可在订单页面打印）
3. 选择快递寄回，运费由我们承担（质量问题）或您承担（无理由退货）
4. 在订单页面填写快递单号

### 第四步：退款处理
收到退货并验收合格后，我们会在1-3个工作日内处理退款：
- 原路退回：支付方式为支付宝、微信的，退款到原账户
- 银行卡退款：退款到原银行卡，到账时间取决于银行处理速度
- 余额退款：退款到平台余额，可下次购物使用

## 运费政策

### 我们承担运费的情况
- 商品质量问题
- 商品错发、漏发
- 商品与描述不符

### 您承担运费的情况
- 7天无理由退货
- 尺寸不合适换货
- 个人原因退货

### 运费标准
- 普通快递：约10-15元
- 顺丰快递：约20-25元
- 具体运费以实际发生为准

## 退款时效

### 处理时效
- 审核申请：1-2个工作日
- 验收退货：1-2个工作日（收到退货后）
- 处理退款：1-3个工作日

### 到账时效
- 支付宝、微信：即时到账
- 银行卡：1-5个工作日
- 平台余额：即时到账

## 特殊商品政策

### 数码产品
- 7天无理由退货需保证包装完整、配件齐全
- 已激活、已联网的数码产品不支持退货
- 质量问题需提供官方检测报告

### 服装鞋帽
- 支持尺寸不合适换货，7天内
- 试穿不影响退换，请勿弄脏、损坏
- 吊牌、标签需完整

### 家居用品
- 定制尺寸不支持退换
- 已安装、使用的家居用品不支持退换
- 质量问题需拍照证明

### 美妆护肤
- 已开封、已使用的美妆产品不支持退货
- 密封包装未开封可7天无理由退货
- 过敏问题需提供医院证明
