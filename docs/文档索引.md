## 🔍 关键信息速查

### 环境要求
- Python: 3.9+
- Node.js: 16+
- MySQL: 8.0+
- Chroma: 本地向量数据库
- DashScope: 阿里云LLM（可选，可降级到Ollama）

### 核心技术栈
- **后端**: FastAPI + SQLAlchemy + MySQL + Chroma + DashScope/Ollama
- **前端**: React + TypeScript + Vite + Ant Design + React Router
- **AI**: RAG架构（检索增强生成）

### 关键配置文件
- 后端环境变量: `backend/.env`（参考 `.env.example`）
- 前端代理配置: `frontend/vite.config.ts`
- 数据库初始化: `database/init_db.sql`
