# 运行指南

## 环境要求

### 系统要求
- **操作系统**: Windows 10+, macOS 10.15+, Linux
- **Python**: 3.9+
- **Node.js**: 16+
- **MySQL**: 8.0+
- **内存**: 至少4GB（推荐8GB）
- **磁盘**: 至少10GB可用空间

### 外部依赖
- **DashScope API Key**: 用于LLM和Embedding（可选，可使用本地模型）
- **Ollama**: 用于本地LLM（可选，需单独安装）

## 快速开始

### 1. 克隆项目

```bash
git clone <repository-url>
cd 5day
```

### 2. 后端设置

#### 2.1 创建虚拟环境

```bash
cd backend
python -m venv venv

# Windows
venv\Scripts\activate

# macOS/Linux
source venv/bin/activate
```

#### 2.2 安装依赖

```bash
pip install -r requirements.txt
```

#### 2.3 配置环境变量

复制 `.env.example` 为 `.env` 并配置：

```bash
cp .env.example .env
```

编辑 `.env` 文件：

```env
# 应用配置
APP_NAME=AI智能客服系统
APP_VERSION=1.0.0
DEBUG=True

# 数据库配置
DATABASE_URL=mysql+pymysql://root:password@localhost:3306/ai_customer_service

# JWT配置
JWT_SECRET_KEY=your-secret-key-here
JWT_ALGORITHM=HS256
JWT_EXPIRE_HOURS=24

# LLM配置
LLM_PROVIDER=dashscope  # 或 ollama
DASHSCOPE_API_KEY=your-dashscope-api-key
DASHSCOPE_MODEL=qwen-plus
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=qwen

# Embedding配置
EMBEDDING_PROVIDER=dashscope  # 或 local
DASHSCOPE_EMBEDDING_MODEL=text-embedding-v3
LOCAL_EMBEDDING_MODEL=paraphrase-multilingual-MiniLM-L12-v2

# Chroma配置
CHROMA_PERSIST_DIR=./chroma_data

# CORS配置
CORS_ORIGINS=http://localhost:5173

# 业务规则配置
DAILY_QUOTA_LIMIT=100
MAX_MESSAGE_LENGTH=500
MAX_FILE_SIZE_MB=10
```

#### 2.4 初始化数据库

```bash
# 登录MySQL
mysql -u root -p

# 创建数据库
CREATE DATABASE ai_customer_service CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 执行初始化脚本
USE ai_customer_service;
SOURCE init_db.sql;
```

#### 2.5 启动后端

```bash
python -m app.main
```

后端将在 `http://localhost:8000` 启动。

API文档地址：`http://localhost:8000/docs`

### 3. 前端设置

#### 3.1 安装依赖

```bash
cd frontend
npm install
```

#### 3.2 启动开发服务器

```bash
npm run dev
```

前端将在 `http://localhost:5173` 启动。

### 4. Spike测试（可选）

## 详细配置

### MySQL配置

#### 创建数据库用户（推荐）

```sql
CREATE USER 'ai_cs_user'@'localhost' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON ai_customer_service.* TO 'ai_cs_user'@'localhost';
FLUSH PRIVILEGES;
```

#### 更新 `.env` 数据库URL

```env
DATABASE_URL=mysql+pymysql://ai_cs_user:your_password@localhost:3306/ai_customer_service
```

### DashScope配置

1. 访问 [阿里云百炼平台](https://bailian.console.aliyun.com/)
2. 创建API Key
3. 在 `.env` 中配置 `DASHSCOPE_API_KEY`

### Ollama配置（本地模型）

#### 安装Ollama

```bash
# macOS/Linux
curl -fsSL https://ollama.com/install.sh | sh

# Windows
# 从 https://ollama.com/download 下载安装包
```

#### 拉取模型

```bash
ollama pull qwen
```

#### 更新 `.env`

```env
LLM_PROVIDER=ollama
```


## 生产部署

### 后端部署

#### 使用Gunicorn

```bash
pip install gunicorn
gunicorn app.main:app -w 4 -k uvicorn.workers.UvicornWorker -b 0.0.0.0:8000
```

#### 使用Systemd（Linux）

创建 `/etc/systemd/system/ai-cs.service`：

```ini
[Unit]
Description=AI Customer Service Backend
After=network.target

[Service]
Type=notify
User=www-data
WorkingDirectory=/path/to/backend
Environment="PATH=/path/to/backend/venv/bin"
ExecStart=/path/to/backend/venv/bin/gunicorn app.main:app -w 4 -k uvicorn.workers.UvicornWorker -b 0.0.0.0:8000
Restart=always

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
sudo systemctl daemon-reload
sudo systemctl start ai-cs
sudo systemctl enable ai-cs
```

### 前端部署

#### 构建生产版本

```bash
cd frontend
npm run build
```

#### 使用Nginx

配置 `/etc/nginx/sites-available/ai-cs`：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /path/to/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    # 后端API代理
    location /api {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # SSE支持
        proxy_buffering off;
        proxy_cache off;
        proxy_set_header Connection '';
        chunked_transfer_encoding on;
    }
}
```

启用配置：

```bash
sudo ln -s /etc/nginx/sites-available/ai-cs /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### Docker部署（可选）

#### 后端Dockerfile

```dockerfile
FROM python:3.9-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 8000

CMD ["gunicorn", "app.main:app", "-w", "4", "-k", "uvicorn.workers.UvicornWorker", "-b", "0.0.0.0:8000"]
```

#### 前端Dockerfile

```dockerfile
FROM node:16-alpine as builder

WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

#### docker-compose.yml

```yaml
version: '3.8'

services:
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: rootpassword
      MYSQL_DATABASE: ai_customer_service
    volumes:
      - mysql_data:/var/lib/mysql
      - ./backend/init_db.sql:/docker-entrypoint-initdb.d/init.sql
    ports:
      - "3306:3306"

  backend:
    build: ./backend
    ports:
      - "8000:8000"
    environment:
      DATABASE_URL: mysql+pymysql://root:rootpassword@mysql:3306/ai_customer_service
    depends_on:
      - mysql
    volumes:
      - chroma_data:/app/chroma_data
      - ./backend/uploads:/app/uploads

  frontend:
    build: ./frontend
    ports:
      - "80:80"
    depends_on:
      - backend

volumes:
  mysql_data:
  chroma_data:
```

启动：

```bash
docker-compose up -d
```

## 常见问题

### 1. 数据库连接失败

**问题**: `Can't connect to MySQL server`

**解决**:
- 检查MySQL是否启动
- 检查 `.env` 中的数据库URL是否正确
- 检查防火墙设置

### 2. 向量化失败

**问题**: `Failed to embed text`

**解决**:
- 检查DashScope API Key是否正确
- 检查网络连接
- 尝试切换到本地模型

### 3. Chroma存储错误

**问题**: `Failed to initialize vector store`

**解决**:
- 检查 `CHROMA_PERSIST_DIR` 目录权限
- 删除 `chroma_data` 目录重新初始化

### 4. 前端CORS错误

**问题**: `CORS policy error`

**解决**:
- 检查 `.env` 中的 `CORS_ORIGINS` 配置
- 确保前端URL已添加到允许列表

### 5. SSE连接断开

**问题**: SSE流中断

**解决**:
- 检查Nginx配置（生产环境）
- 确保 `proxy_buffering off` 已配置
- 检查超时设置
